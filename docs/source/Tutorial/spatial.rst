Explore spatial organization
=============================

**Input:** the classified data examined in :doc:`analysis`, including
coordinates and population labels.

Choose an ROI and coordinate resolution
---------------------------------------

Select a tissue/core and verify its coordinate units and acquisition
resolution. Record the sample/ROI identifier so every screenshot and export
can be traced to the same tissue.

Build and inspect a grid
------------------------

1. Open **Grid Analysis** and select a grid size or target cell count.
2. Define a composition rule using an available classified population.
3. Inspect the grid overlay and the priority/default labels.
4. Select a reference region class and examine its proximity map.

.. admonition:: Screenshot to add

   Show grid parameters, the region rule, and the resulting labeled and
   proximity maps. Include spatial scale and legends.

Compare cell distances and neighborhoods
----------------------------------------

1. Open **Neighborhood Analysis** and choose source and target populations
   present in the ROI.
2. Examine nearest-target distance distributions.
3. Choose a neighbor count and cluster count for cellular neighborhoods.
4. Inspect neighborhood composition alongside the spatial map.

These are different analyses; see :doc:`../spatial` for their definitions.
Record the actual parameters rather than treating manuscript examples as
mandatory settings.

.. admonition:: Screenshot to add

   Capture source/target selections and a distance plot, then neighborhood
   parameters, composition profiles, and the matching tissue map.
