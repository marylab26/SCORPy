SCORPy Documentation
====================

.. image:: ../../resources/SCORPy_full_git.png
   :alt: SCORPy - Single-Cell proteOmics Research Platform
   :width: 650px
   :align: center

SCORPy is a standalone, code-free desktop application for end-to-end analysis
of multiplexed imaging spatial single-cell proteomics data. It guides users
from post-segmentation CSV files through preprocessing, cell classification,
and spatial analysis.

New users should start with :doc:`installation`, then follow the
:doc:`example-data tutorial <Tutorial/tma>`. Experienced users can go directly
to the relevant workflow module.
